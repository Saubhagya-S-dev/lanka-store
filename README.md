# 🛍️ LankaStore.lk - E-Commerce Web Application

### 📝 Project Description
A fully responsive E-Commerce web application built using HTML, CSS, Vanilla JavaScript, and integrated with Firebase Firestore for real-time data management.

### ✨ Key Features
- **Responsive UI/UX:** Optimized for Mobile, Tablet, and Desktop screens.
- **Admin Dashboard:** Ability to add new products and manage inventory in real-time.
- **Customer Frontend:** Dynamic product listing loaded from Firebase Firestore with "Add to Cart" functionality.

### 🛠️ Tech Stack
- Frontend: HTML5, CSS3, JavaScript (ES6+ Modules)
- Database: Cloud Firestore (Firebase)
